### Ilkham Yabbarov

Computational chemist at McMaster University (ChemAI Lab). NSERC CREATE AccelD trainee.
I build open tools for multi-objective molecule design and open data for IR spectroscopy.

**Projects**

- [ParetoMol](https://github.com/IlkhamFY/paretomol): free web app for multi-objective Pareto analysis of drug-like molecules. Published in *Digital Discovery* 2026 ([doi:10.1039/d6dd00366d](https://doi.org/10.1039/d6dd00366d)). Live at [paretomol.com](https://paretomol.com).
- [IRexp](https://huggingface.co/datasets/ilkhamfy/IRexp): open dataset of 239,735 experimental IR band lists from open-access chemistry papers. v0.2 on Hugging Face and [Zenodo](https://doi.org/10.5281/zenodo.23463965).
- [qSTCH-Set](https://github.com/IlkhamFY/qstch-set) and [STCH-BoTorch](https://github.com/IlkhamFY/stch-botorch-public): smooth Tchebycheff scalarization for many-objective Bayesian optimization in BoTorch.
- [epistemic-foraging](https://github.com/IlkhamFY/epistemic-foraging): MCP server and CLI that gives AI agents verified literature evidence. On PyPI as [foragekit](https://pypi.org/project/foragekit/).
